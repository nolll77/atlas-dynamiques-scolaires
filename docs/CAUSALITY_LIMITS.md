# Limites de causalité — Note méthodologique

## Ce que ce projet fait

Cette étude identifie des **associations statistiques robustes** entre le profil
socio-économique des lycées (IPS, σ), leur localisation géographique,
le contexte résidentiel (revenus IRIS, prix DVF) et les dynamiques de réseau.

## Ce que ce projet NE fait PAS

❌ Il ne prouve pas que X cause Y.
❌ Il ne prédit pas le comportement individuel (ecological fallacy).
❌ Il ne formule pas de recommandations de politique publique.

## Formulations

| ❌ À éviter | ✅ À utiliser |
|---|---|
| "Ce lycée exclut les défavorisés" | "Ce lycée présente un profil de forte concentration sociale" |
| "Le privé cause la ségrégation" | "Les données sont cohérentes avec une association" |
| "La réforme X réduira les inégalités" | "Le modèle suggère que X pourrait réduire les inégalités, sous hypothèse de comportements statiques" |
